ScribeTrace UI Screen Gallery

Static HTML mockups powered strictly by design/tokens.css. No external fonts, no CDNs, calm and dense scholarly desktop aesthetic.

The 3-3-3-3 User Journey Architecture

Every screen serves an explicit Requirement ID (R-ID) and a defined 3-3-3-3 journey step (docs/debate/08-links-and-3-step.md).

1. Install (2–3m)
  1. Download installer
  2. Run package
  3. Open app < 2s
2. Setup (2m)
  1. Allow Zotero access
  2. Choose project folder
  3. Connect to Zotero
3. Onboarding (2m)
  1. Pick paper from list
  2. Import marks (< 5m)
  3. Copy quote (< 10m)
4. Everyday
  1. Read/mark in Zotero
  2. Click Refresh (< 5s)
  3. See what changed
