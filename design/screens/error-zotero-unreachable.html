ScribeTrace — Connection Status
R-04, R-02 • 3-3-3-3 Setup (Step 3) | Friction Moment #2

Cannot reach Zotero at 127.0.0.1:23119

ScribeTrace could not connect to Zotero's local interface. This usually means Zotero is not running, or its local access setting is switched off. ScribeTrace does not retry in the background (R-04).

How to fix this in under one minute:

  1. Open Zotero on this computer.
  2. Open Zotero's preferences:
    • On macOS: Zotero → Settings → Advanced
    • On Windows / Linux: Edit → Preferences → Advanced
  3. Under Advanced, check the box:
    ☑ Allow other applications on this computer to communicate with Zotero
  4. Return here and click Check Connection Again below.
Check Connection Again Back to Setup
Honest Privacy Invariant (R-02, R-03, SEC-1): ScribeTrace communicates exclusively over loopback (127.0.0.1:23119) on an explicit user click. It never modifies your Zotero database, never starts a background daemon, and never transmits data to any external server.
